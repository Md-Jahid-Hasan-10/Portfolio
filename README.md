A single-page, fast, professional personal portfolio for **Jahid Hasan**, a backend-focused software engineer building event-driven banking microservices.

## ✨ Highlights

- **Dark by default**, with a light/dark toggle that persists across visits.
- **Featured project** — Event-Driven Banking Microservices — with an animated SVG architecture diagram (no image asset needed).
- **Animated counters** that count up on scroll for competitive-programming stats.
- **Typewriter role line** rotating through `Backend Engineer · Microservices & Event-Driven Systems · Competitive Programmer`.
- **Copy-to-clipboard** email with a "Copied!" toast.
- Fully responsive from **360px → 1280px+**, with a slide-in mobile menu.
- Accessible: semantic landmarks, one `h1`, skip-to-content link, visible focus rings, `prefers-reduced-motion` respected.
- SEO: metadata, Open Graph, Twitter card, JSON-LD `Person`, `sitemap.xml`, `robots.txt`, dynamic favicon and OG image.

## ✏️ Editing Content

**All text, links, projects, skills and dates live in one file:**

```
src/data/content.ts
```

Nothing is hardcoded in components — edit that file and the whole site updates. It exports:

| Export | What it controls |
|---|---|
| `site` | Name, title, description, canonical URL, OG image, CV path |
| `navLinks` | Navbar links and section order |
| `hero` | Greeting, name, rotating roles, pitch, stats, CTAs, profile image |
| `socials` | GitHub / LinkedIn / Codeforces / CodeChef links + handles |
| `about` | Paragraphs and the three quick-fact cards |
| `experience` | Timeline entries (title, org, period, description) |
| `projects` | Project cards, stack chips, highlights, links, images |
| `skillGroups` | Skill category cards and their chips |
| `counters` / `achievements` | Animated stats and achievement cards |
| `education` | Degree, institution, period, CGPA |
| `contact` | Heading and invite copy |
| `footer` | Copyright year and "built with" line |

### Adding a project

```ts
{
  id: "my-project",
  title: "My Project",
  summary: "One line for the card.",
  description: "Optional longer paragraph.",
  stack: ["Spring Boot", "Kafka"],
  highlights: ["First highlight", "Second highlight"],
  links: [{ label: "GitHub", href: "https://github.com/you/repo" }],
  image: "/projects/my-project.png",  // optional
  imageAlt: "Describe the screenshot for screen readers",
}
```

The first project with `featured: true` renders as the full-width card. Set `diagram: true` to render the SVG architecture diagram instead of an image.

### Placeholder / TODO convention

Any value still starting with `TODO_` is treated as "not provided yet":

- Buttons whose link is still a `TODO_` are **not rendered** (no dead links).
- `site.url` and `site.ogImage` fall back to safe local values.

Search for `TODO` in `src/data/content.ts` to find them.

## 🖼 Replacing Assets

All assets live in `public/`. Just overwrite the file — no code changes needed.

| File | Used for | Notes |
|---|---|---|
| `public/Jahid_Hasan_CV.pdf` | "Download CV" button | Overwrite the file to update your CV — no code change needed. |
| `public/profile.png` | Hero avatar | Portrait works best. Fallback initials avatar `JH` renders automatically if the file is missing. |
| `public/projects/foodio.png` | Foodio card | |
| `public/projects/digitvision.png` | DigitVision card | |
| `public/projects/banking-microservices.png` | Banking card | *Optional* — the featured card currently uses the SVG diagram instead. |
| `public/og-image.png` | Social share preview | Auto-generated by `src/app/opengraph-image.tsx`; a static file here overrides it. |

**Why keep the CV local rather than a Google Drive link?** Files in `public/` are deployed *with* the site, so the download works permanently from your own domain, at full speed, with no Drive consent screen. If you later delete the local copy, the deployed site is unaffected.

## 🚀 Deploy to Vercel

### Option A — Vercel CLI

`vercel` is already a devDependency in this project, so no global install is needed:

```bash
cd portfolio
npx vercel login      # one-time browser confirmation
npx vercel            # preview deployment
npx vercel --prod     # production deployment
```

### Option B — GitHub + Vercel Dashboard

The repo is already pushed to `github.com/Md-Jahid-Hasan-10/Portfolio` and the site files sit at the **repository root** (`package.json`, `next.config.mjs`, `src/`, `public/`), which is what Vercel expects.

1. **Push future changes**
   ```bash
   cd portfolio
   git add .
   git commit -m "your message"
   git push origin main
   ```
2. **Import on Vercel**
   - Go to [vercel.com/new](https://vercel.com/new)
   - Click **Add New → Project** and import your repository
   - Vercel detects Next.js automatically — leave the build settings as-is
   - Click **Deploy**
3. **Add your domain** *(optional but recommended)*
   - Vercel assigns a free `*.vercel.app` URL immediately
   - For a custom domain: **Project → Settings → Domains → Add**, then point your DNS A/ANAME record at Vercel
### Canonical URL — nothing to do

The canonical URL, Open Graph `og:url`, `sitemap.xml` and `robots.txt` **resolve the live host automatically at request time** via `resolveSiteUrl()` in `src/data/content.ts`. There is no URL to hardcode, and no manual step after deploying, renaming the project, or adding a custom domain.

To override it anyway, set one environment variable in **Vercel → Settings → Environment Variables**:

| Variable | Effect |
|---|---|
| `NEXT_PUBLIC_SITE_URL` | Forces the canonical URL to this value (trailing slash trimmed). Leave unset to auto-detect. |

### Environment variables

None required. The site is fully static — no secrets, no database, no API keys.

## 🔌 Adding a Contact Form Later

The site deliberately uses `mailto:` only, so there is no backend to maintain or leak. If you want a form:

- **Formspree** — create a form, get an endpoint ID, then POST to it from a small client component.
- **Resend** — add a server route that sends via the Resend SDK, then call that route from the form.
- **Vercel Forms** — if you migrate to a React Server Component form.
